DASHBOARD WIREFRAME EKRAF SUMEDANG

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ini di Visual Studio Code.
3. Buka index.html.
4. Klik kanan > Open with Live Server (jika ekstensi Live Server terpasang), atau klik dua kali index.html untuk membukanya di Chrome.

Empat tampilan:
1. Pengambil kebijakan - Desktop
2. Pengambil kebijakan - Smartphone
3. Pengolah data - Desktop
4. Pengolah data - Smartphone

Catatan:
Ini prototype visual HTML/CSS/JavaScript, belum terhubung ke CSV/database. Angka yang tampil berdasarkan rekap yang sudah diperiksa. Placeholder digunakan untuk rincian kecamatan/kategori yang belum tersedia. Jangan menampilkan data pribadi pada dashboard publik.
